# 🌿 マスマスター1（MathMaster 1）
**中学1年生向け 数学AI学習補助Webアプリ**

中学生が毎日楽しく、視認性高く学べるように「黄緑色（ライトグリーン）」を基調としたクリーンで洗練されたデザインの学習補助アプリケーションです。

---

## 🌟 主な機能と特徴

### 1. 🏠 モード選択画面（ホーム）
- **「① 日々の授業復習モード」** と **「② テスト前総復習モード」** をワンクリックで選択可能。
- 現在の連勝記録や到達難易度、学習履歴へのアクセスがひと目でわかります。

### 2. ✏️ ① 日々の授業復習モード
- **ページ数入力**：授業で進んだ教科書のページ（例: `p.42〜43`）を入力すると、自動で該当単元（正負の数の乗除、文字と式、1次方程式など）をマッピング！
- **教科書写真アップロード機能**：
  - ファイル添付またはカメラ撮影に対応。
  - AIが写真から重要公式や例題のエッセンスを自動スキャンし、その範囲にぴったりな「計算問題」と「文章問題」を生成します。

### 3. 📝 ② テスト前総復習モード
- **テスト範囲の一括指定**：ページ範囲（例: `p.10〜50`）や単元チェックボックスからテスト範囲を柔軟に設定可能。
- 範囲全体の重要問題を網羅し、総まとめ特訓ができます。

### 4. ⚡ 1問ずつ進む「アダプティブ（適応型）出題」＆難易度自動アップ
- **テンポのよい1問1答形式**：一度に大量に出題せず、1問解くごとに即座に解説とフィードバック！
- **計算問題**：テキスト入力欄に数値や式（例: `-4`, `4x`, `x=5` など）を直接入力。全角半角やスペース、表記揺れにも柔軟に対応します。
- **文章問題（ノート写真提出対応）**：
  - ノートに書いた立式や途中式の解き方プロセスを **「写真（カメラ撮影/添付）」** で提出可能！
  - AIが途中式のプロセスや思考力を解析し、どこが素晴らしいか、どこでつまずいたかを褒めてアドバイスします。
- **エンドレス自動レベル調整**：
  - 正解するたびに難易度が自動で昇格（Lv.1 基礎確認 → Lv.2 標準 → Lv.3 応用 → Lv.4 発展 → Lv.5 難関突破）。
  - お子様が「続ける」限り、次々と新しい問題にエンドレスで挑戦できます！

### 5. 👨‍👩‍👦 保護者用ダッシュボード（進捗共有機能）
- **学習指標の一目でわかる可視化**：
  - 勉強した日数、累計クリア問数、平均正答率、現在の到達難易度
  - 最近勉強した教科書ページ範囲
- **ビジュアルグラフ（Plotly）**：
  - 単元別の正答率バーグラフ
  - 日別の学習問数推移グラフ
- **AIからのつまずき分析＆家庭での声かけヒント**：
  - 符号ミスや移項の忘れなど、最新の学習ログからお子様のつまずき傾向を分析。
  - 親御さんがご家庭で温かく褒めて自己肯定感を高められる「具体的な声かけフレーズ」を提示します。

## 🚀 起動方法

### 1. すぐに起動する場合（現在サーバー稼働中）
現在すでにローカルサーバーが起動しています。ブラウザで以下のアドレスを開くだけです：
👉 **http://localhost:8501**

### 2. 次回以降の起動方法
本フォルダ内にある **`run_app.bat`** をダブルクリックするだけで、自動的にブラウザが開いて起動します。

手動でコマンドプロンプトやPowerShellから起動する場合は以下を実行してください：
```powershell
.\.venv\Scripts\streamlit.exe run app.py
```

## 🤖 AI連携（Gemini API）について
本アプリは**ハイブリッド設計**となっています：
- **APIキーなし（オフライン内蔵AIエンジン）**：
  初期状態のまますべての機能（単元自動判定、問題自動生成、途中式判定シミュレータ、詳細解説、保護者アドバイス）が100%快適に動作します。
- **Google Gemini APIキーを連携する場合**：
  サイドバーの「Gemini APIキー」入力欄にキーを入力すると、Gemini最新のマルチモーダルモデルによる高度なリアルタイム画像OCR添削・オリジナル問題生成が有効になります。
